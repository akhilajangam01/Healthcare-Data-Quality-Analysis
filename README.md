# Healthcare Data Quality Analysis

## Project Overview
This project analyzes a healthcare dataset for data quality issues and explores key health risk factors associated with heart disease. The project includes data validation, statistical exploratory data analysis (EDA), and an interactive Tableau Public dashboard.

## Tools Used
- Python
- pandas
- scipy
- Jupyter Notebook / VS Code
- Tableau Public
- Excel
- GitHub

## Analysis Performed
- Data quality profiling and validation
- Missing value and duplicate checks
- Healthcare risk-factor analysis
- Statistical exploratory data analysis
- Chi-square significance testing
- Comparison of heart disease with smoking and diabetes
- BMI and exercise-habit analysis
- Tableau dashboard development

## Reproducibility
1. Download the healthcare dataset.
2. Place the dataset in the `data` folder.
3. Open `healthcare_data_quality.ipynb`.
4. Install/import the required Python libraries, including pandas and scipy.
5. Run the notebook cells in sequence.
6. Review the generated data-quality and statistical outputs.
7. Use the cleaned data for visualization in Tableau Public.

## Tableau Dashboard
An interactive Healthcare Data Quality Dashboard was created and published using Tableau Public.
